# AI 开发工作流调度平台 - 功能设计文档

## 1. 功能概述

本文档详细描述 AI 开发工作流调度平台的各项功能模块、用户界面设计、交互流程和实现细节。

## 2. 用户角色

### 2.1 角色定义

| 角色 | 描述 | 权限 |
|------|------|------|
| 系统管理员 | 平台管理者 | 所有权限 |
| 项目负责人 | 项目创建和管理者 | 项目的全部操作权限 |
| 开发人员 | 项目协作者 | 项目的编辑和查看权限 |
| 观察者 | 项目查看者 | 项目的只读权限 |

## 3. 功能模块详细设计

### 3.1 用户管理模块

#### 3.1.1 用户注册
- **输入：** 用户名、邮箱、密码
- **验证：** 邮箱唯一性、密码强度
- **输出：** 注册成功提示、自动登录

#### 3.1.2 用户登录
- **输入：** 用户名/邮箱、密码
- **验证：** 账号密码匹配
- **输出：** JWT Token、用户信息
- **功能：** 记住登录状态、自动登录

#### 3.1.3 用户信息管理
- 查看个人信息
- 修改个人信息（头像、昵称、邮箱）
- 修改密码
- 账号安全设置

### 3.2 项目管理模块

#### 3.2.1 创建项目

**页面布局：**
```
┌────────────────────────────────────────┐
│          创建新项目                      │
├────────────────────────────────────────┤
│ 项目名称: [__________________]         │
│                                         │
│ 项目类型: ○ 前端 (Vue3)                │
│          ○ 后端 (Spring Boot)          │
│                                         │
│ 项目描述: [____________________]       │
│          [____________________]       │
│                                         │
│ 模板仓库: [默认模板] [▼]               │
│                                         │
│        [取消]  [创建项目]               │
└────────────────────────────────────────┘
```

**字段说明：**
- **项目名称**（必填）：3-50 个字符，支持中英文、数字、下划线
- **项目类型**（必填）：前端（Vue3）或后端（Spring Boot）
- **项目描述**（可选）：最多 500 字符
- **模板仓库**（必填）：下拉选择预设的模板仓库

**创建流程：**
1. 用户填写项目信息
2. 点击"创建项目"按钮
3. 后端验证数据
4. 从模板仓库克隆代码
5. 初始化项目结构
6. 返回项目详情页面

**异常处理：**
- 项目名称重复 → 提示用户修改
- 模板仓库访问失败 → 提示网络错误，稍后重试
- 初始化超时 → 标记项目状态为"初始化失败"，允许重试

4. 异步调用第三方 API 获取每个组件的源码和截图
5. 实时更新获取进度
6. 完成后显示组件列表

## 5. 数据交互

### 5.1 前后端接口约定

**请求格式：**
```json
{
  "method": "POST",
  "url": "/api/v1/projects",
  "headers": {
    "Authorization": "Bearer <token>",
    "Content-Type": "application/json"
  },
  "body": {
    "name": "项目名称",
    "type": "FRONTEND",
    "description": "项目描述"
  }
}
```

**响应格式（成功）：**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "name": "项目名称",
    "type": "FRONTEND",
    "status": "INITIALIZING",
    "createdAt": "2024-01-20T10:30:00Z"
  }
}
```

**响应格式（失败）：**
```json
{
  "code": 400,
  "message": "项目名称已存在",
  "errors": [
    {
      "field": "name",
      "message": "项目名称已存在"
    }
  ]
}
```

### 5.2 WebSocket 实时通信

**连接：**
```javascript
const ws = new WebSocket('ws://localhost:8080/ws/coding-tasks/123');
```

**消息格式：**
```json
{
  "type": "PROGRESS_UPDATE",
  "taskId": 123,
  "progress": 50,
  "message": "正在生成页面框架代码...",
  "timestamp": "2024-01-20T10:32:00Z"
}
```

**消息类型：**
- `PROGRESS_UPDATE`: 进度更新
- `LOG_MESSAGE`: 日志消息
- `STATUS_CHANGE`: 状态变更
- `TASK_COMPLETED`: 任务完成
- `TASK_FAILED`: 任务失败

## 6. 异常处理

### 6.1 网络异常
- 请求超时：提示用户稍后重试
- 连接失败：检查网络连接
- 服务不可用：显示维护通知

### 6.2 业务异常
- 数据验证失败：高亮错误字段并提示
- 权限不足：跳转到无权限页面
- 资源不存在：提示资源已被删除
- 操作冲突：提示刷新后重试

### 6.3 系统异常
- 服务器错误：显示友好的错误页面
- 未知错误：记录日志并提示联系管理员
